# API reference

The JSON API is a fully-supported alternative to the [ISO 8583 API](TSP_ISO_Message_V2.9.md): both
front the same underlying tokenization service and the same input data, so behaviour, validation
rules and data element meaning are shared between them. See
[Choosing an interface](choosing_an_interface.md) for how the two compare, and
[Tokenization concepts](tokenization.md) for the concepts that apply regardless of which interface
you integrate against.

This page renders the OpenAPI specification for the JSON interface.

!!! note

    The specification is published in the repository at
    `openapi/ctsp-web-service-interface/ctsp-token-api.yaml` and is currently marked as a draft.
    Contact the Stø Token Service support team before implementing against it.
